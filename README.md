# 旅行图志

Windows / macOS 本地旅行素材管理和地图演示应用。原始图片、视频和地图只记录路径，不复制、不移动。每次旅行保存为一个 `.travel` JSON 项目，自动保存并保留上次版本 `.bak`；缩略图在应用数据目录缓存。

已生成安装包：`release/0.2.1/旅行图志 Setup 0.2.1.exe`。也可以直接打开 `release/0.2.1/win-unpacked/旅行图志.exe`，保留同目录其他文件。源码目录内的 `启动旅行图志.cmd` 可以启动已构建的开发版本。

## 开发与运行

需要 Node.js 22+ 和 pnpm。

```powershell
pnpm install
pnpm build
pnpm desktop
```

热更新开发：先运行 `pnpm dev`，另一个 PowerShell 窗口运行：

```powershell
$env:TRAVEL_DEV_URL='http://127.0.0.1:5173'
pnpm desktop
```

`pnpm test` 验证演示领域规则；`pnpm dist` 构建 Windows 安装包，输出到 `release/`。安装包关联 `.travel` 文件。

### macOS 运行与打包

在 Mac 上使用 Node.js 22+ 安装依赖并构建。

```bash
pnpm install --frozen-lockfile --registry=https://registry.npmjs.org
pnpm dist:mac
```

默认按当前 Mac 的架构打包：Apple Silicon 为 arm64，Intel 为 x64。在对应架构的 Mac 上分别安装依赖和打包；`ffmpeg-static` 的可执行文件随安装机器的架构选择，不要直接复用另一架构的 `node_modules` 来交叉打包。

产物位于 `release/`：`旅行图志-0.2.15-mac-arm64.dmg`、同名 `.zip`，以及 `mac-arm64/旅行图志.app`（Intel 为 `mac/旅行图志.app`，安装包名中的架构为 `x64`）。DMG 用于拖入「应用程序」安装，ZIP 用于分发应用副本。打包后的应用加载内置页面，不需要 Vite 服务或浏览器。

只生成 `.app`、跳过 DMG / ZIP：

```bash
pnpm dist:mac:dir
open "release/mac-arm64/旅行图志.app"
# Intel Mac 改为 open "release/mac/旅行图志.app"
```

当前使用 ad-hoc 签名（`identity: "-"`），无需 Apple 开发者证书，未配置 Apple 公证，适合本机运行和内部测试。正式对外分发前应配置 Developer ID 签名、Hardened Runtime 和 Apple 公证。macOS 包保留视频解析、缩略图和照片元数据所需的 macOS 二进制及 ExifTool Perl 文件；Windows 仍保留原有打包方式。

Apple Silicon 使用原生 `@ffprobe-installer/darwin-arm64` 解析视频，不依赖 Rosetta；安装依赖时请保留 optional dependencies（不要使用 `--no-optional`）。Intel Mac 和 Windows 继续使用 `ffprobe-static`。

## 使用

### 项目导出、导入与路径配置（0.2.15）

项目页面左侧提供「导入项目」「导出项目」「配置文件路径」，首页也可「导入项目」。原有「打开项目」用于继续编辑原项目；「导入项目」始终另存为独立项目。

导出默认不携带原件，生成 `.travel` 副本。勾选「导出素材原件」后生成项目 ZIP，包含全部关联图片、视频、地图、独立封面和不参加演示的素材；同一路径的文件只复制一份。导出副本保留地点、路线、标点、备注、封面和演示设置，当前项目及原件不会被修改。

导出弹层中的「配置文件路径」打开单独的路径弹层。按每个实际文件夹列出去重后的文件数量，各文件夹独立映射，不支持父目录批量替换。仅修改文件夹，保留文件名，所有共享引用同时更新。不携带原件时可输入 Windows 盘符、网络路径或 macOS 路径；携带原件时配置 ZIP 内相对目录，例如 `素材/意大利`。不同文件映射到同一目标路径时必须先解决冲突。目标电脑的路径无需在导出电脑上存在。

导入接受导出的 `.travel` 或项目 ZIP。普通项目选择新的保存位置；ZIP 选择落地目录，自动创建项目专属子目录，同名目录使用新名称而不覆盖。路径弹层允许输入路径或选择本地文件夹，ZIP 默认关联包内素材。导入后的包内路径以相对路径保存，整体移动项目文件夹后仍可打开。选择外部目录的引用仍依赖外部目录。

项目页面的路径配置确认后立即保存。弹层显示找到、缺失的文件数量及缺失清单；有缺失时仍可确认，稍后修复。携带原件导出遇到缺失文件时默认阻止导出，只有明确勾选「跳过缺失文件继续导出」才继续，缺失引用仍保留。取消路径配置或导入不会修改当前项目。

验证：`pnpm test` 覆盖路径映射与 ZIP 往返；桌面流程使用 `pnpm test:project-transfer`，需安装 Playwright 或通过 `PLAYWRIGHT_PATH` 指定它的位置，打包验证可通过 `TRAVEL_TEST_EXE` 指定应用可执行文件。

新建项目并选择保存位置，通过左侧地点树管理地点。在素材页多选文件导入，或拖入文件夹递归导入。素材默认拍摄时间排序（缺失依次回退修改时间、创建时间），可以拖动重排。一个项目内同一路径不重复归属。移动下拉框只改变地点归属。

地点树左侧箭头可以展开或折叠，折叠状态随项目保存；搜索时临时展开匹配路径。拖动素材悬停在折叠地点上，会自动展开，方便拖入后代地点。

点击素材打开详情弹层：左侧预览图片或视频，右侧设置是否参加演示、设为地点封面、移动到其他地点、重新定位缺失文件或删除引用。卡片中不再显示这些操作按钮。

开启“选择”后，点击卡片切换选中状态，可以全选、批量删除、批量不参加演示或恢复参加演示。选中的素材可以作为一组在列表中排序，组内保持原顺序；拖到左侧地点时，按原顺序追加到目标地点末尾。拖动未选中素材只处理这一份。拖动时左侧下方出现垃圾桶，松开移除引用，原始文件保留。关闭选择或切换地点时清空选择。

排除演示的图片、视频保留在管理界面，带“不参加演示”标记；不参与播放、演示计数、标点层叠数量和默认封面候选。无地图且没有可演示素材时，如果有可用的手动封面则保留标点，仅展示封面、不可点击；连封面也没有时隐藏标点。

地图页上传图片，选择任意后代地点添加标点，拖动标点定位。每张地图每个地点只允许一个标点。同分支只展示最上层已标记地点。有地图或可演示素材的地点可以进入；只有可用封面的地点显示不可点击的静态标点。无地图、无可演示素材、无可用封面的地点隐藏。有地图但无素材、无封面时显示无素材图标。封面可从当前地点整棵子树选择。

地点也可以导入独立封面图片，不加入素材列表、不计入素材数量、不参与演示。通过素材详情或封面选择器手动指定的封面也独立保存路径，素材移动、排除演示或删除引用后仍保留。封面文件缺失时回退到默认封面；可用“恢复默认”清除手动封面。旧版项目的手动封面打开时自动迁移。

演示从当前选中地点开始。有地图时显示地图，角落素材堆只包含直属素材。点击素材堆放大素材，地图缩到角落且不能点击标点。点击角落地图或最后一张的“返回地图”恢复地图。

无地图时依次展示整棵子树：直属素材优先，然后按子地点顺序递归展开，中途忽略后代地图。最后一张显示“返回上一级地图”。面包屑仅显示实际经过的地点。

左右方向键切换素材，空格播放/暂停视频，Esc 退出演示。视频默认暂停，结束后停留；切走时暂停。当前演示内保留每个地点的素材位置和地图视野。素材保持比例完整显示，黑色填边，鼠标静止时隐藏演示控件。

路径检查标记缺失文件，管理界面可以重新定位；演示跳过缺失文件。开始演示前也会自动检查路径。配置误改时，可将 `.travel.bak` 复制并改成 `.travel` 打开；原始素材仍需在记录的路径中存在。

## 边界

视频播放依赖 Electron 内置媒体解码能力，容器扩展名不保证内部编码受支持。不支持的图片或视频在演示中跳过并显示空状态；兼容预览转码还未实现。大文件夹导入在后台进程串行解析元数据和缩略图，界面显示忙碌状态。

单独的 `.travel` 项目文件不包含素材，拷贝它到另一台电脑不能自动携带素材。可使用「导出素材原件」生成项目 ZIP 再导入，或保留原始目录并配置失效路径。

### 地图路线与分步演示

在「地图与标点」中点击「绘制路线」，依次点击底图上的起点、途经点、终点，然后点击「完成路线」。每条路线是一项演示步骤，支持上移、下移、删除，设置动画时长，并选择内置的飞机、小轿车、大巴、高铁或吉普车图标。

演示从未展示路线的状态开始；点击「下一步」或按右方向键 / 空格逐步播放。路线箭头逐渐延伸，交通图标沿途经点移动，已完成路线保留。动画中再次前进可直接完成本步；左方向键返回上一步，「重播」清空演示进度。

「显示地点位置」控制地图上的地点封面和名称；编辑中的设置随项目保存，演示中也可临时切换。旧项目默认显示地点。

### HEIC / HEIF 照片

支持将 HEIC / HEIF 照片用于缩略图、封面、大图预览和演示。首次读取时在后台线程生成原分辨率的 JPEG 展示缓存（质量 95%），保留原始文件和项目中的原文件路径。重复打开复用缓存；原文件大小或修改时间变化后会重新转换。转换完全在本机进行，无需安装系统 HEIF 扩展。旧项目中的照片也会自动使用此流程。

详情和演示中的当前照片优先于后台缩略图转换，已有展示缓存直接读取，避免素材较多时大图排在整页缩略图之后长时间黑屏。仍限制为一次解码一张大图，避免批量读取占用过多内存。macOS 的系统级 HEIC 支持不会自动替代应用的 JPEG 预览缓存流程。

桌面验证：`pnpm test:heic -- <HEIC样本路径>`；默认使用 `.test-data/heic/example.heic`。公开测试样本来源：[libheif example.heic](https://github.com/strukturag/libheif/blob/master/examples/example.heic)。

### 全窗口地图编辑（0.2.3）

在「地图与标点」中点击地图右上角的「放大编辑」。地图铺满应用窗口，左侧浮层管理地点标点及显示开关，右侧浮层管理路线、交通工具、步骤和动画时长，两侧均可收起。底部提供缩放比例、放大、缩小和完整显示地图。点击「完成编辑」或按 Esc 返回原页面；地图视图和未完成的路线草稿在进入、退出全窗口时保留，已完成编辑自动保存。

滚轮以鼠标位置为中心缩放地图，不会滚动外部页面。在工具浮层中使用滚轮只滚动工具列表，不会缩放地图或滚动外部页面。

### 弧线路线与地点名称（0.2.4）

完成路线后，直接按住地图上的路线线条向侧面拖动，即可调整该段弧度；起点、终点和途经点保持原位。多段路线的各段可以独立拖弯。交通工具和箭头动画沿弧线移动，箭头方向跟随曲线切线；旧路线默认保持直线。路线卡片中的「恢复直线」可清除该路线的弯曲设置。

「显示地点位置」改为「显示地点名称」，只控制地图上的名称文字。关闭时，相册图案的位置、显示和点击入口均保持不变。此设置随项目保存，演示中也可临时切换。旧项目的开关状态自动用于名称显示。

### 路线选择、端点与步骤排序（0.2.5）

先点击地图上的路线，或点击右侧步骤卡片选中路线。第一次点击只选中；选中后才出现起点、终点、途经点和十字移动手柄。拖动各个圆点可改变位置，拖动线条可调整弧度，拖动十字手柄可平移整条路线。拖动端点、途经点时会保留相邻段的相对弧度；移动整条路线时全部点和弧度一起平移，并限制起终点位于地图内。

Delete 或 Backspace 删除当前选中的路线；未选中路线时不执行删除。在交通工具、动画时长等输入控件中，删除键继续用于编辑文字。点击地图空白处可取消选择，重新打开项目也会清除临时选中状态。

右侧卡片左上角的拖动手柄可上下拖拽排序，同步调整演示步骤。路线形状、交通工具、时长和选中状态都跟随路线本身。原有上移、下移按钮仍可使用。

### 分层地图动画进度（0.2.6）

同一次演示中，每个地点分别记住地图动画的步骤和当前进度。进入子层级或查看本层素材时，地图动画暂停；返回后恢复原有路线和箭头位置，已完成步骤不会从头播放。未完成的一步可点击「继续本步」或按右方向键 / 空格从暂停位置继续。

「重播」只重置当前层的动画。退出整场演示后重新开始，所有层级的动画进度归零；演示进度不会写入旅行项目文件。

### 时长输入与地图设置布局（0.2.7）

动画时长支持完整的小数输入过程，例如清空后依次输入 `0`、`.`、`5`，不会在输入到 `0` 时被强制改值。按 Enter、移开焦点或退出全窗口编辑时确认输入，再应用 0.2–60 秒的范围限制；空值、无效文本恢复原值。

「地图与标点」页的封面、添加标点、名称开关及路线工具移到地图上方，步骤列表可展开收起。地图预览使用宽幅画布并按窗口高度限制尺寸，底图完整适配、不变形，页面内工具不再遮挡底图。全窗口编辑仍使用左右工具浮层。

### 地点树滚动与演示素材缩放（0.2.8）

切换地点只重新创建右侧内容区，左侧目录保持原有滚动位置和展开状态。切换地点时清理上一地点的素材拖拽状态，避免旧拖拽操作影响新地点。

演示中的照片和视频支持 0.5–5 倍缩放。使用左上角的加减按钮或在画面上滚轮缩放，放大后按住画面拖动查看局部，定位按钮恢复 100% 适配比例。切换素材时恢复 100%。视频缩放后提供独立的播放、进度与静音控制，避免原生控制条随画面放大被裁掉。

### 演示过渡、备注与默认 80%（0.2.9）

点击子层级相册或当前地点相册时，从相册位置展开进入，返回时反向收回；新图片载入后淡入。过渡约 0.3 秒，保留原有地图动画进度。系统设置减少动态效果时，自动省略这些过渡。

演示地图的缩放工具、路线播放栏默认 25% 不透明度，鼠标悬停或键盘聚焦后完全显示；地点相册和路线保持正常显示。

在图片的「素材详情」中编辑「图片备注」，随项目自动保存。演示时在底部控制栏上方显示半透明备注条，默认最多三行，长备注可展开、滚动和收起；空备注不占空间。窄窗口中备注会避开缩略地图，备注内容不写入原图。

照片、视频的默认显示和复位比例均改为 80%，缩放范围仍为 0.5–5 倍。切换素材时恢复 80%。

### 全局参加演示筛选（0.2.10）

「素材与地点」页新增「仅显示参加演示」开关。全应用只有一个筛选状态，所有地点层级共用；切换地点、标签页或重新启动应用后保持生效，作为本机界面偏好保存。

开启后按实际演示规则显示素材：隐藏已设为不参加演示或文件缺失的素材。地点入口保持可导航，子地点素材数量反映当前筛选。全选、批量操作和素材拖拽限定在当前可见素材，隐藏后的选择会自动清理。没有符合条件的素材时可点击「显示全部素材」关闭全局筛选。筛选本身不修改参加演示设置，也不删除原有素材。
