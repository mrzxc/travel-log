# 旅行图志的分类与演示约定

生成适配本项目的地图和 `.travel` 时阅读。能访问源码时核对 `src/model.ts` 的数据结构和 `visiblePins`；以下与当前 version 1 相符。

## 分类树和演示路径

分类树记录真实归属；演示路径记录实际点击。例如分类为“欧洲旅行 → 意大利 → 罗马 → 斗兽场”，总览图可以直接标罗马而不标意大利。进入后的面包屑为“欧洲旅行 → 罗马”，结束回总览，没有意大利入口。

节点自由命名和排列，深度不限。有地图的节点先展示地图。角落素材堆只播放直属素材；放大素材后地图缩到角落且不可点击标点，末页“返回地图”恢复当前地图。

没有地图的节点直接连续预览自身及全部后代素材，不展示子地点入口，不在中途切入后代地图。顺序为直属素材优先，再按 children 顺序递归；结束返回实际进入它的地图。如果用户希望进入罗马后选择景点，应给罗马配地图，并使其出现在可进入的父地图上，不能完全藏在一个无地图的连续预览入口下。

## 标点规则

- 每张图可标任意后代地点，同地点只标一次；不同地图独立定位。
- 标点保存在地图所属节点的 `pins`，不是目标地点的全局坐标。
- 同一分支只显示当前图最上层的有效标记。有效指目标有可用地图，或整棵子树有可用素材。
- 未标记的分类层级不进入实际演示面包屑。
- 没地图且无素材的子树标点隐藏；有地图但无素材的标点显示“无素材”图标。
- 封面可取整个地点子树的素材；默认按展示顺序取第一份可用素材，视频取第一帧。最多 5 层，仅顶层显示封面，其余白边由应用绘制，底图不要预画。

## 机制示例

```text
欧洲旅行 [地图：欧洲总览]
├─ 意大利 [分类节点，无地图]
│  ├─ 罗马 [地图：罗马市区]
│  │  ├─ 斗兽场 [无地图，素材预览]
│  │  └─ 万神殿 [无地图，素材预览]
│  └─ 威尼斯 [无地图，子树连续预览]
└─ 奥地利 [无地图，子树连续预览]

欧洲总览入口：罗马、威尼斯、奥地利；不标意大利。
罗马市区入口：斗兽场、万神殿。
```

示例不替用户决定层级。空项目中罗马有地图，能显示；其他无素材的入口暂时隐藏，导入照片后出现。

## `.travel` version 1

```json
{
  "version":1,"id":"trip-unique-id","name":"欧洲旅行","rootId":"trip",
  "nodes":{
    "trip":{
      "id":"trip","name":"欧洲旅行","parentId":null,"children":["rome"],"media":[],
      "map":{"id":"map-trip","path":"C:/Maps/trip.png","name":"trip.png","type":"image","time":1792800000000},
      "pins":[{"nodeId":"rome","x":0.46,"y":0.63}]
    },
    "rome":{"id":"rome","name":"罗马","parentId":"trip","children":[],"media":[],"map":null,"pins":[]}
  }
}
```

`x/y` 范围 `[0,1]`，原点为图片左上角，按完整图片宽高归一化。纬度向北增加，而图片 y 向下增加；用真实投影的像素位置除以宽高，不能直接填 lon/lat。图片裁切、扩边后重算。PNG 可直接导入；SVG 是可编辑源，当前导入器不接受 SVG。

项目只有一个 `parentId:null` 根；所有节点/children 一致且从根可达。无用户素材时 `media:[]`，不填 `coverId`，不要把地图加进 `media` 伪造素材。
